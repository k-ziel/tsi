# Nauka – Odnośnik jako blok

## Cel

Każdy link w menu ma stać w **osobnym wierszu**, na szerokość kontenera menu — jak lista pionowa, bez Flexa.

## Przydatne

`a` jest domyślnie `inline`. Ustaw `nav a { display: block; }` plus kolor, brak kreski, padding i cienką ramkę. Blokowe linki układają się jeden pod drugim. Hover złoty jak w dziale o linkach.

## Wymagania

1. `title`: `Display — kolumna`.
2. `nav a`: `display: block;`, `color: #1e4d7b;`, `text-decoration: none;`, `padding: 8px;`, `border: 1px solid #1e4d7b;`.
3. `nav a:hover`: `color: #c9a227;`.
4. Autor, stopka.

## Oczekiwany wynik

Otwórz stronę: Start i Stopka jeden pod drugim, każdy w ramce na szerokość menu. Najedź — złoty kolor tekstu.
